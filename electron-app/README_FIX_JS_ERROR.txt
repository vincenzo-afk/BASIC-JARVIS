IMPORTANT: DO NOT DOUBLE-CLICK .JS FILES!

If you are seeing a "Microsoft JScript runtime error", it is because you are trying to run a JavaScript file (like electron.js) by double-clicking it. Windows tries to run it as a system script, which fails.

TO RUN JARVIS CORRECTLY:
1. Go to the main JARVIS folder.
2. Double-click "CLICK_TO_START.bat".

This will automatically start the Backend and Frontend correctly.
